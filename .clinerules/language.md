# 回答言語

**すべての回答を日本語で書く。** コード中の識別子やコミットメッセージは英語のままにする。

- ユーザーへの説明、報告、確認、質問はすべて日本語
- コード内のコメントも日本語を既定とする（既存の `app.js` / `styles.css` /
  `tools\*.ps1` は日本語コメントで統一されている）
- **日本語の文に他言語の語句を混ぜない。** 中国語・韓国語・英語の語が
  文中に紛れ込んだ文章は、書き直す。
- **書き終えたら読み返す。** 日本語として不自然な語が残っていないか確かめてから出す。
- `.ps1` は Windows PowerShell 5.1 が BOM なしファイルを ANSI と誤読して日本語が壊れる。
  スクリプト内で日本語リテラルを使う場合は、リポジトリ既存の `tools\*.ps1` と同じく
  コードポイントから組み立てる（`function U { param([string]$hex) ... }`）。
- ファイルを書き換えたときは、中身が別の文字列に化けていないか読み返して確かめる。

## 実装にあたって

- **推測を事実として書かない。** 検証していない計算式やデータ構造は、実データで確認してから書く。
  確認できなかったものは、その旨を明示する。
- **データに無いものを表示しない。** 値を推測で埋めた表は利用者の判断を誤らせる。
  計算できないなら「その値がデータに無い」と書く。
- 既存の規約に従う。CSS は共通ルールへ追加して重複定義を避ける。
  表のヘッダを `position: sticky` で固定するなら背景は不透明にする。
- 他言語の文字が混入していないか、リポジトリ全体を走査して確かめる。
